# Madhav-E-commerce-Sales-Dashboard
🚀 Overview

This project presents an interactive Ecommerce Sales Dashboard built using Power BI. It provides key business insights such as sales performance, profit trends, customer behavior, and category-level analysis.

The dashboard is designed to help stakeholders quickly understand performance and make data-driven decisions.

📌 Key Features
🔹 KPI Metrics
Total Sales Amount: 438K
Total Profit: 37K
Total Quantity Sold: 5615
Average Order Value (AOV): 120.9K

🛠 Tools & Technologies
Power BI – Data visualization
Excel / CSV – Data source
DAX – Calculations and measures

🎯 Business Use Case
This dashboard helps:
Track sales and profitability trends
Identify high-performing regions and products
Analyze customer purchasing behavior
Optimize payment methods and operations
